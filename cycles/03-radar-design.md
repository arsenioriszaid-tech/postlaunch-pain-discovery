# OPPORTUNITY RADAR — design lock (24 Sep 2026, paralel sprint D1)
Bukan pencari ide abstrak. Bukan penambah sumber. Bukan build. Output = experiment-ready packet ATAU kill beralasan.

## Pipeline (wajib berurutan, tak boleh loncat)
DISCOVER → EVIDENCE → CLUSTER → ECONOMIC FILTER → ADVERSARIAL CHECK → EXPERIMENT DESIGN → TARGETING → HUMAN-READY.
EXPERIMENT READY mensyaratkan: ≥2 independent behavioral instances + economic consequence terukur (Rp/jam/event) + existing workaround/spend ATAU penjelasan tertulis mengapa tetap ekonomis (confidence turun) + counterevidence dicari dan dijawab + event volume cukup (≥10 event/14 hari) + minimal 3 target accessible + eksperimen manual tanpa software.

## Status (bukan ranking, bukan skor)
KEEP (kuat, tunggu slot eksperimen) · EXPERIMENT READY (lolos threshold) · NEEDS EVIDENCE (kurang link chain) · WATCH (menarik, frekuensi/volume belum cukup) · KILL (masuk graveyard + alasan).

## Evidence chain (9 link, tandai per link: PROVEN/WEAK/UNTESTED)
PAIN → RECURRING → LOSS → WORKAROUND/SPEND → INTERVENTION → CARES → WTP → REPEATABLE → AUTOMATABLE. Klaim rantai penuh HANYA jika semua link PROVEN.

## Batas harian
Maks 3 kandidat baru/hari. Maks 1–2 EXPERIMENT READY/hari. Jika tak ada yang lolos: tulis TIDAK ADA.

## Anti-pattern (DILARANG)
Complaint-count = market · testimonial vendor = validasi · reply/"interesting" = validasi · weak signal → conviction · riset manual untuk Nio · Nio baca puluhan sumber · pindah market karena DM sepi.

## Prioritas vs sprint
Sprint (outbound + concierge aktif) = prioritas #1. Radar = pipa paralel. Jika founder merespons eksperimen: hentikan discovery, eksekusi. Jika sunyi: isi pipa target berikutnya.
