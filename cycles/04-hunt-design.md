# 100-TARGET HUNT — design lock (24 Sep 2026)
Arena diperluas, bar evidence TETAP. "100" = throughput pencarian, bukan target spam, bukan asumsi hasil.

## Funnel (throughput, bukan janji)
100 RAW → QUALIFIED (fit ≥2 kriteria: recurring workflow + economic consequence terlihat) → CONTACTABLE (kanal publik + personalization hook) → APPROVED (Nio) → CONTACTED → RESPONSES → EXPERIMENTS → OUTCOMES.
Status target HANYA: RAW/QUALIFIED/CONTACTABLE/APPROVED/CONTACTED/REPLIED/EXPERIMENT/CONVERTED/NO RESPONSE/REJECTED/DISQUALIFIED.

## Batch terkontrol
- Batch A: 25 target (turn ini). Inspeksi kualitas + asumsi messaging. Nio APPROVE sebelum kirim.
- Batch B/C/D: +25 tiap batch hingga 100. Syarat lanjut: kualitas evidence Batch sebelumnya terjaga + ada sinyal dunia nyata (balasan/akses) ATAU alasan tertulis.
- Batch I sprint (7 kontak) jalan independen, tak tersentuh hunt.

## Aturan keras
- DILARANG: build/MVP/landing/automation/integration/software; kirim DM atas nama Nio; klaim menghubungi; hitung duplikat sebagai independen; complaints = validation; silence/reply/"interesting" = validasi ekonomi; pindah market karena DM sepi; riset manual untuk Nio.
- Opportunity baru maks 3/hari (kualitas). Target discovery tak dibatasi SELAMA evidence kuat.
- EXPERIMENT READY hanya jika: recurring pain jelas + economic consequence + workaround/spend plausibel + target accessible + eksperimen manual terkecil + baseline + threshold sukses + kill condition + jalur outcome terukur.
- Setiap kill → graveyard + alasan. Setiap READY → packet + 3–5 target + DM draft (TIDAK dikirim).
- Rantai 9-link ditandai PROVEN/PARTIAL/UNKNOWN per link. Tak ada winner, tak ada skor.
